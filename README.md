# equicidade.com.br

Site institucional da Equicidade, publicado pelo GitHub Pages a partir da branch `main`.

O mapa com login fica em outro repositório (`mapa-equipamentos-publicos`) e vai para `mapa.equicidade.com.br`, no servidor próprio.

## Estrutura

- `index.html`: a página
- `assets/css/style.css`: estilos, com as cores da marca no início
- `assets/js/main.js`: menu do celular e formulário (abre o WhatsApp com os dados preenchidos)
- `assets/img/`: logos em SVG e imagem de compartilhamento
- `CNAME`: domínio do Pages

Antes de divulgar, troque o exemplo "Bairro Planalto, 1.240 crianças" do topo por um caso real.
